# English 小站 (static site)

Static frontend served by GitHub Pages at https://admax12959.github.io/english/.
Audio mp3s are not committed: the Pages workflow generates them with edge-tts (`scripts/gen_audio.py`) and caches them.
Progress is kept in the browser (localStorage). `public/tunnel.json` is updated by the study box with its current
tunnel URL so the page can sync progress to the box.

No personal data or credentials belong in this repo.
